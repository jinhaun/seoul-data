# 장소별 수집 완료 검사

- 시간대별 대상은 저장된 장소 목록과 최신 목록을 합친 결과입니다. 현재 121곳이며 한 곳이라도 누락되면 미완료입니다.
- 완료 기준은 장소명·실제 인구 기준 시각·혼잡도·인구 최소 및 최대값입니다. 0명은 유효하고 빈 값·음수·역전된 범위는 무효입니다.
- 같은 시간 안에서 장소별 관측 1건을 확보합니다. 분 단위 기준 시각이 완전히 같다는 뜻은 아닙니다. 원래 기준 시각을 보존하며, 다른 시간 응답은 그 실제 시간에 저장하고 이전 시간을 채운 것으로 세지 않습니다.
- 먼저 받은 자료는 수정하거나 지우지 않습니다. 누락 장소만 1분 간격 최대 두 번 추가로 시도하고, 미완료 시간은 후속 바퀴에서도 기준 시간 시작 후 110분 이내에 다시 확인합니다.
- 장소별 재시도 묶음은 약 8분의 예산을 두며, 진행 중인 통신 요청 하나의 대기시간만큼 늘 수 있습니다. 새 서버로 넘기는 기존 기능도 유지합니다.
- 새 검사표 `data/status/수집완료검사.csv`는 검사시각·시간대·대상수·유효수·상태·누락장소를 추가 기록합니다. 예전 수집기록의 열은 유지하되 보충 시 누적 완료 상태가 추가될 수 있으므로 행 개수 대신 고유 시간대와 최신 상태를 확인합니다.
- 기준 시간 시작 후 110분이 지나도 미완료이면 기존 슬랙 시험 채널에 부분 누락을 한 번 알립니다. 재시도 중이거나 완료된 시간은 알리지 않습니다. 시간대 전체 누락 알림도 유지합니다.
- 알림 전송 실패 시 보낸 기록을 남기지 않아 다음 바퀴에 다시 시도합니다. 시험 실행은 메시지 전송·알림 기록 저장을 하지 않습니다.
- 추가 원본은 날짜·시간·고유값을 붙인 이름으로 압축 보관하여 기존 원본을 덮어쓰지 않습니다. 예측 보충과 노트북 자료의 자동 합치기는 하지 않습니다.
- 외부 원천의 데이터 미제공이나 GitHub 전체 중단까지 완전히 방지할 수는 없습니다. GitHub 전체가 멈추면 같은 실행기에 있는 슬랙 경고도 멈춥니다.

## 변경 뒤 확인

`tests/collection_quality.tests.ps1`과 `tests/collector_integration.tests.ps1`을 PowerShell에서 실행합니다. 실제 인증값·서울시 접속·슬랙 전송 없이 시험합니다. 첫 운영 실행 후 새 검사표의 대상수와 유효수, 실제 자료의 장소 수, 압축 원본 보관을 확인합니다.

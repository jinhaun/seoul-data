# 서울매시간 방문 시간 비교

첫 화면은 장소별 요일·시간 평균 인구입니다. 현재 수집 과정에서 사이트 요약을 만들 때 `scripts/build_visit_patterns.py`도 실행합니다. 별도의 컴퓨터나 인증 설정은 필요하지 않습니다. 기간은 최근 1·3·6개월·1년 중 고르며, 날짜별 기록에서는 날짜 지정과 시간 막대 이동으로 그날 인구·관측 혼잡도를 확인합니다.

## 기간과 계산

- 한국 시간 오늘을 제외한 직전 달력 개월을 사용합니다. 2026년 11월 26일 기준 1개월은 10월 26일~11월 25일, 3개월은 8월 26일~11월 25일, 6개월은 5월 26일~11월 25일, 1년은 2025년 11월 26일~2026년 11월 25일입니다. 말일은 대상 달의 마지막 날짜로 맞춥니다. 자정을 지난 뒤 수집 자료가 사이트에 반영되면 기간도 하루 이동합니다.
- 원본은 `data/realtime/월/날짜.csv`입니다. 수집한 시각이 아닌 **인구기준시각**으로 날짜와 시간을 구분합니다.
- 같은 장소·기준시각의 중복은 한 번만 사용합니다. 값이 서로 다르면 먼저 수집된 유효 행을 사용하고 충돌 건수를 남깁니다. 수집 시각이 없는 행보다 시각을 아는 행을 우선합니다.
- 같은 날짜·장소·시간에 여러 관측이 있으면 최소·최대 인구를 먼저 평균 냅니다. 이후 같은 요일·시간의 날짜별 값을 같은 비중으로 평균 냅니다. 30분 관측이 있는 날에 가중치를 더 주지 않습니다.
- 화면의 평균 인구는 서울시 추정 최소·최대 범위 중앙값의 평균입니다. 상세 칸에서 최소·최대 평균도 볼 수 있습니다.
- 빈 값·잘못된 범위는 제외합니다. 실제 0명은 유효합니다. 자료가 없는 칸은 비워 두고 0명이나 예측값으로 채우지 않습니다.
- 각 칸은 실제 관측 날짜 수 / 선택 기간 안의 해당 요일 날짜 수를 표시합니다. 칸을 누르면 날짜 목록과 수집 시작 전 날짜 수, 수집 시작 후 빠진 날짜 수가 나옵니다. 수집 시작은 전체 누적 자료의 첫 유효 인구 기준시각 날짜입니다. 한 시간 안에 일부 관측만 있어도 그 날짜는 관측 1일이며, 이는 하루 전체 관측을 뜻하지 않습니다.
- 하루 평균 요약은 24시간 자료가 모두 있는 날만 계산합니다. 시간별 인구를 더한 고유 방문자 수가 아닙니다.
- 공휴일도 해당 요일에 포함합니다. 과거 평균으로 미래 인구를 보장하지 않습니다.

## 화면과 내려받기

색의 범위는 선택한 장소의 전체 요일·시간 평균을 기준으로 정합니다. 서울시 공식 혼잡도와 다릅니다. 장소 순위는 같은 요일·시간 평균으로만 비교하며, 장소 면적이 다르므로 인구가 적다고 밀도가 낮다고 단정하지 않습니다.

`site/visit-manifest.json`은 저장된 날짜와 기간별 파일 주소를 담습니다. `site/patterns/1.json`, `3.json`, `6.json`, `12.json`이 각 기간 평균이며, `data/analysis/방문시간_요일시간_숫자개월.csv`가 해당 내려받기 표입니다. 표에는 121곳 × 7요일 × 24시간의 평균·최소·최대·관측일·대상일·누락일·관측 날짜·수집 전 날짜·수집 후 누락 날짜가 들어갑니다. 관측 없는 평균은 빈칸입니다. 기존 최근 30일 주소 두 개도 그대로 생성해 이전 연결을 보존합니다.

날짜별 기록은 `site/history/월/날짜.json`에 누적합니다. 날짜를 골랐을 때 그날 파일만 받아오므로 누적 기간이 길어져도 전체 날짜를 한꺼번에 불러오지 않습니다. 지난 파일도 지우지 않고 원본이 보충되면 다시 계산합니다. 오늘의 일부 자료도 날짜별 기록에서 볼 수 있지만 기간 평균에서는 제외합니다.

날짜별 큰 숫자는 그 시간대 유효 인구 범위 중앙값의 평균입니다. 상세에는 관측 기준시각별 최소·최대와 원본 혼잡도를 모두 표시하며, 서로 다른 혼잡도 등급을 하나의 평균 등급으로 바꾸지 않습니다. 빈 시간은 그래프 선을 잇지 않습니다. 시간 막대는 한 시간씩 움직이고 시간 칸·이전/다음 버튼·방향키로도 조작할 수 있습니다. 선택 장소·기간·조회 방식·날짜·시간은 주소에 보존합니다.

주 저장소는 깃허브 `data/realtime`의 날짜별 표이며, 구글 시트는 별도 자동 정리 프로그램이 만드는 월별 사본입니다. 사이트는 깃허브 자료에서 자동 계산합니다. 구글 시트의 자료와 구조를 바꾸는 작업은 이번 변경에 포함하지 않습니다.

집계 검사: `python -m unittest discover -s tests -p test_visit_patterns.py -v`

공개 자동 검사 `방문 시간 평균 계산 검사`도 계산 프로그램 변경 시 실행합니다. 집계에 실패하면 사이트 요약 만들기도 실패하므로 잘못된 새 결과를 성공으로 처리하지 않습니다.

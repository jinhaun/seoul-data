## 기본 정보
- 프로젝트 폴더: C:\Users\Administrator\Desktop\프로젝트  (PC에 Python 없음 → PowerShell 사용, CSV는 -Encoding UTF8 로 읽기)
- 이 작업은 **읽기 전용**입니다. 프로젝트 폴더의 파일을 수정·삭제·이동하지 마세요. config.txt 의 인증키는 읽지도 출력하지도 마세요.
- 보고 기간: 실행일 기준 **지난주 월요일 ~ 일요일 7일** (예: 11/10(월) 실행 → 11/3(월)~11/9(일)).
- 사용할 Slack 도구: slack_send_message, slack_get_file_upload_url, slack_complete_file_upload. 채널은 반드시 C0CECMMTA49 만 사용하세요. 다른 채널·사람에게 보내지 마세요.

## 1. 수집 현황 (기간 7일, 날짜별)
- 실시간 데이터: data\YYYY-MM-DD_요일\ 폴더에서 이름이 `^\d\d(00|30)\.json\.gz$` 인 파일 수 (하루 48개가 정상). 빠진 시각(HHmm)이 있으면 적으세요 (12개 넘으면 "n회 (첫~끝)"으로 줄여서).
- 행사: 같은 폴더의 이벤트_공식.csv, 이벤트_웹검색.csv 있으면 O, 없으면 X (웹검색은 행 수도).
- 외국인·관광: 외국인_관광\YYYY-MM\YYYY-MM-DD_요일\ 폴더의 숙박 파일 상태 (변화없음 / 변경내역 있음). 변경내역 CSV가 있으면 구분(신규/변경/삭제) 건수를 셉니다.
- 오류: logs\YYYY-MM.log 에서 기간 안의 ERROR/WARN 줄 수와 대표 내용 1~3개 (각 100자 이내).
- 전체 갱신: logs\update_all_YYYY-MM-DD.log 의 마지막 줄로 각 날짜의 성공 여부.

## 2. 주간 핵심 숫자
- 외국인_관광\합본\외국인생활인구_단기_전체.csv (열: 날짜, 요일, 주말여부, 시간, 자치구코드, 자치구, 생활인구합계, 중국, 일본, 미국, 태국, ... 국적별). 이 데이터는 약 4일 늦게 올라오므로 **파일에 있는 가장 최근 7일**을 "이번 7일", 그 앞 7일을 "직전 7일"로 비교하고 실제 날짜 범위를 함께 적으세요.
  - 하루 값 = 그날 25개 구의 시간별 값을 모두 더한 뒤 24로 나눈 값(하루 평균 인원). 여러 날은 더하지 말고 평균을 내세요. 빈칸은 0.
  - 서울 전체 단기체류 외국인 하루 평균 (이번 7일 vs 직전 7일, 증감률)
  - 하루 평균이 많은 구 상위 5개 (이번 7일)
  - 국적 상위 6개 (중국·태국·미국·일본·몽골·베트남 등 실제 상위)와 직전 7일 대비 증감률
  - 이번 7일 안의 평일 평균 vs 주말 평균
- 환율: 환율\환율_일별.csv 가 있으면 원/달러·원/100엔·원/위안의 기간 마지막 값과 그 1주 전 값, 증감률.
- 숫자는 "그 시간에 있던 사람 수의 평균"이라 중복 없는 방문객 수가 아니라는 점을 한 줄로 덧붙이세요.

## 3. Slack에 올리기
1. 위 1·2를 하나의 메시지로 만들어 slack_send_message 로 C0CECMMTA49 에 보냅니다. 제목 예: "📊 주간 데이터 보고 (11/3~11/9)". 마크다운 표 사용 가능, 5000자 이내. 문제가 있었던 날(48개 미만, 오류)은 눈에 띄게 표시하세요.
2. 파일: 최종_데이터\최종_데이터.xlsx (약 100MB). 파일 수정 시각이 실행일 기준 3일 이내일 때만 올리고, 오래됐거나 없으면 올리지 말고 메시지 끝에 그 사실을 적으세요.
   - slack_get_file_upload_url(filename = "최종_데이터_YYYYMMDD.xlsx", content_length = 파일의 정확한 바이트 수)
   - 받은 URL은 그대로 변수에 넣어 curl 로 원본 바이트를 POST: `curl -sS -X POST "$URL" -H "Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet" --data-binary "@파일경로"` (URL을 손으로 고치지 말 것, 실패 시 새 URL 발급)
   - slack_complete_file_upload(file_id, channel_id = "C0CECMMTA49", thread_ts = 1번 메시지의 ts, initial_comment = "이번 주 최종 데이터 파일입니다 (수정 시각 ...)")
   - 업로드가 실패하면 1번 메시지 스레드에 실패 사실만 짧게 남기세요.
3. 마지막 답변: 보낸 메시지 링크, 파일 업로드 여부, 발견한 문제를 3줄 이내로 요약.

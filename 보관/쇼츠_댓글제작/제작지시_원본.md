## 만드는 방법 (기존 틀 재사용)
- 렌더러·음성·음악은 `국가대항전\`(renderer.cs, tts.py, 영상만들기.ps1)과 `테크쇼츠\`, `음악\음악넣기.py`를 참고해 그대로 쓴다. 새로 만든 파일은 모두 작업 폴더 안에 둔다. 기존 폴더 파일은 고치지 않는다.
- 목소리: edge-tts 현수(ko-KR-HyunsuMultilingualNeural) +15%. 대본 톤은 기존 쇼츠와 같게(짧고 반전 있게). BGM은 음악\경쾌.wav 또는 잔잔.wav에 덕킹.
- 1080x1920, 30~50초. 모바일 안전영역 x60–900 / y220–1460. 자막은 크게, 2줄 이하.
- 주제별 색 테마를 정한다. 실제 기업·인물 로고는 쓰지 않는다.
- PowerShell 5.1: .ps1은 UTF-8 BOM으로 저장. 파이썬은 `python -X utf8`. ffmpeg가 PATH에 없으면 Machine+User PATH를 합쳐서 찾는다.

## 검증 (가장 중요)
- 작업 폴더에 `검증.py`를 만든다. 영상에 쓴 숫자 데이터(작업 폴더의 json)를 **원본 CSV에서 csv 모듈로 다시 계산해** 비교하고, 화면 텍스트·대본에 나오는 모든 숫자가 그 값과 일치하는지 확인한다. 하나라도 다르면 이유를 출력하고 exit 1, 모두 맞으면 "통과"를 출력하고 exit 0.
- 이 검증.py는 제작이 끝난 뒤 감시 프로그램이 **다시 실행한다**. 작업 폴더 안에서 단독으로 돌아가야 한다.
- 숫자를 확인할 수 없으면 지어내지 말고 실패로 끝낸다.

## 끝나면 반드시 {작업폴더}\결과.json 을 쓴다
성공: {"통과": true, "영상": "<음악 넣은 mp4 절대경로>", "썸네일": "<png 절대경로>", "파일이름": "<짧은 한글 이름>", "제목": "<유튜브 제목 #Shorts 포함>", "설명": "<2~3줄 + 출처·기준일>", "해시태그": "#..."}

Slack 전송·.env 읽기·업로드는 하지 않는다 (감시 프로그램이 한다).
